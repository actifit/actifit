# Release codenames

Each release gets a codename from **body chemistry**: the molecules exercise makes or uses. Take the next unused name from the list, in order.

Where the codename goes:
- Play Console release name: `vX.Y.Z (build) · Codename`
- The release notes doc title and the announcement post title, for example *Actifit v0.16.1 "Endorphin"*

Users never see the Play Console release name. They only see the codename in the announcement post.
